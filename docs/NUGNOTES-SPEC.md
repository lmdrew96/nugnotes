# NugNotes spec

Photograph your handwritten class notes; NugNotes reads them, ties a course's sessions together into themes, threads, connections and arcs, flags what's never explained (whiskers) or doesn't match, and Nugget quizzes you from it.

**Source of truth:** the ChaosPatch spec **"NugNotes: paper notes that connect"**, the primary spec on the `nugnotes` project (id `5d8929c2-b2c2-4e45-b36b-8120d2394a0f`). This file is only a pointer; the spec is kept and edited there.

**How to read it:**

- From Claude Code or Claude chat with ChaosPatch connected: `cp_get_spec` with `project_slug: "nugnotes"`.
- In the ChaosPatch web app: project NugNotes → Spec.
